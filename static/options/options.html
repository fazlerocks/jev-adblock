API key

Create a key in the TypeSafe console . It is stored only in this browser's extension storage and sent only to api.typesafe.ai.

Privacy

For each element that looks like it might be an ad, the extension sends TypeSafe:

  • the page's hostname, title and language
  • the element's tag, class names, ARIA role and label, size (and the standard ad-size name if it matches one), position and page region
  • the hostnames (never full URLs) of links and iframes inside it, and whether any link is marked rel="sponsored"
  • the names of any ad-tech attributes on it, and which of the extension's own heuristics flagged it
  • up to 150 characters of its visible text

Never sent: form values, cookies, full URLs, or page text outside the candidate element. Pages with a password field or a payment iframe are never analysed. Decisions are cached locally, so repeat visits usually send nothing. No telemetry.

Blocking

Thresholds are the minimum aggregate ad probability required to hide. Higher means fewer false positives.
