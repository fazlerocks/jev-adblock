Jev Ad Blocker

An AI-only ad blocker. Instead of filter lists, page elements that look like ads are described in a few structural fields and judged by TypeSafe AI's Jev model using your own API key.

1. API key

Create a key in the TypeSafe console. It is stored only in this browser's local extension storage and is sent only to api.typesafe.ai.

2. What leaves your browser

For each element that looks like it might be an ad, the extension sends TypeSafe:

  • the page's hostname, title and language
  • the element's tag, id, class names, ARIA role/label, size, position and which page region it sits in
  • the hostnames (never full URLs) of links and iframes inside it
  • up to 150 characters of its visible text

Never sent: form values, cookies, full URLs, or page text outside the candidate element. Pages with a password field or a payment iframe are never analysed. Decisions are cached locally so repeat visits send nothing.
